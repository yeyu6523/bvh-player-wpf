# 播放器界面约定

## Scope and visitor mode

Operate：用户载入 BVH，观察骨架动作，并控制播放。主操作区为三维视口，右侧显示文件信息和速度控制，底部为播放按钮与时间轴。

## Task and content

打开文件后停在首帧，提供播放、暂停、调速、定位、逐帧和循环。清楚标记帧号、原始采样率、关节和通道数量。内置示例为原创生成数据。错误载入保留此前动作。

## Form

seed:df9a2f6851cbe486。实现采用简洁的运动分析教学工具布局：深色三维观察区、浅色原生控制面板、一种蓝色操作强调色。方案根据用户已明确的程序功能与专业默认值执行，没有额外的设计确认流程。

## First viewport

1320 × 860 默认窗口。左侧三维骨架占主要面积，左/右侧骨骼分别以青色/暖橙区分，中轴为浅色。播放和速度在首屏可见。界面信息和控件在 1080 × 760 最小窗口仍应可操作。

## Signature interaction

暂停时逐帧观察运动，选择骨骼树节点后高亮相应关节并显示通道顺序。通过拖动旋转视角，滚轮缩放，右键拖动平移。

## Verification and boundaries

逐个解析全部提供的 BVH 数据，使用独立列向量参考算法核对姿态。验证实际 exe 的启动、文件打开、播放/暂停、调速、拖动时间轴。使用 Windows 原生组件，不运行 HTML/CSS 检测器。代码仓库不收录原课件、视频或原始课件工程。
